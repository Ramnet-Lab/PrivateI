Cloudflare Access service token — only if this endpoint sits behind Cloudflare

Some endpoints cannot be reached directly: a Cloudflare tunnel stands in front and asks every caller who it is before letting the request through. A service token is how a program gets past that door — a client id and a client secret, issued together by whoever set the tunnel up. Both are sent with every request, both are read by Cloudflare, and neither reaches the model. They do not replace the API key above: the door and the model server check different things, and a request behind Access has to satisfy both. Leave both boxes empty if nobody has handed you a token.

A service token needs both halves. Cloudflare finds the token by its client id and then checks the secret against it, so one without the other is not half a credential — it is refused at the door, and what comes back is a sign-in page instead of an answer. Fill in both boxes, or empty the client id to remove the token altogether.
